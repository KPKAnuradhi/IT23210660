# IT23210660 — Playwright Tests

Quick setup and test commands for this project.

Install dependencies (if not already installed):

```powershell
cd "C:\Users\USER\Desktop\IT23210660"
npm install
npx playwright install
```

Run tests (headless):

```powershell
npx playwright test
```

Run tests in headed mode:

```powershell
npx playwright test --headed
```

Open the HTML report:

```powershell
npx playwright show-report
```
